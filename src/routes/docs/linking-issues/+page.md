---
title: "Linking issues"
description: "Link Jira issues to persona profiles with the Personas custom field or from the persona's issue screen, one persona or many."
---

There are two ways to link Jira issues to persona profiles.

If you configured the Personas for Jira custom field as described in [setup](/docs/setup), you can select your persona from the dropdown list. You can also add multiple personas via the custom field.

![Selecting a persona from the custom field on an issue](/docs/IssuePreview.png)

The other way is to go into the persona profile, click "Issues" in the top right-hand corner and then search and add your issues from the overview screen.

![Adding issues to a persona profile](/docs/IssueScreen.png)

If you have configured the custom field as described above, the custom field will be set. Otherwise, an issue property is set which holds the persona assignment.
