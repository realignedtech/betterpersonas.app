---
title: "Searching for issues"
description: "Use the generated JQL query from a persona profile to find related Jira issues, and filter Story Maps for Jira by persona."
---

In order to make it easier to find issues associated with a persona profile, Personas for Jira offers a search preview.

When you go to the issue assignment screen in the persona profile, you can click "View Query", even if no issues are assigned yet. You will see the generated query which you can use in other places in Jira.

![The generated JQL query for a persona](/docs/ViewQuery.png)

![Searching for issues to add to a persona](/docs/IssueSearch.png)

Additionally, other apps like Story Maps for Jira and Advanced Story Maps for Jira both offer integration with Personas for Jira. You can filter both apps for the persona profiles maintained within the same project.
